Cosmos · ATOM

鍵が別の端末にある Cosmos ウォレット

Cosmos Hub、Osmosis、Injective、THORChain、Stride、Juno を、Keplr と同じやり方で Cosmos のアプリにつながる Chrome と Brave の拡張機能で。署名する鍵のほうは、ネットワークをまったく持たないスマートフォンかパソコンに置いたまま。取引は QR コードになって渡り、署名されて戻ってきます。

拡張機能を入手

6 つのチェーン、ひとつの鍵

Cosmos Hub、Osmosis、Injective、THORChain、Stride、Juno。どのアドレスも、すでにお持ちの同じリカバリーフレーズから、そのチェーン自身の導出パスと接頭辞で作られます。cosmos1、osmo1、inj1、thor1、stride1、juno1 です。

オフライン端末が SignDoc を読み直す

拡張機能は、何に署名するのかをボールトに教えません。渡すのはバイト列です。ボールトは protobuf の SignDoc を自分でデコードし、見分けられたメッセージに名前を付け、メモを省略せずに表示し、読めないものは拒みます。乗っ取られたブラウザが、取引を別のものとして語ることはできません。

Cosmos のアプリはいつもどおりつながる

拡張機能は Cosmos のアプリが想定する Keplr の API に応答するので、Osmosis、Stride、DAO DAO、Injective Helix、THORSwap からはふつうのウォレットに見えます。モックではなく、実際のサイトに対して測っています。

authz の委任は赤で出る

MsgGrant は、あなたの資産を動かす権利を別のアカウントに渡します。メッセージの並びの中では何の変哲もない一行に見えて、このチェーンで静かに支配権を手放す唯一のものです。だから確認画面はこれを赤くし、はっきりした同意を求めます。MsgRevoke ではそうしません。

Cosmos ウォレット: よくある質問

Locker Protocol Wallet はどの Cosmos チェーンに対応していますか？

Cosmos Hub（ATOM）、Osmosis（OSMO）、Injective（INJ）、THORChain（RUNE）、Stride（STRD）、Juno（JUNO）です。6 つとも同じリカバリーフレーズから生まれ、それぞれのチェーンのアドレス接頭辞を持ちます。

秘密鍵がパソコンに置かれることはありますか？

ありません。鍵はネットワークにつながっていない 2 台目の端末、Locker Vault の中にあります。予備のスマートフォン、タブレット、パソコンに入れる無料のアプリです。拡張機能が持つのは公開鍵とアドレスだけ。取引は QR コードで表示され、ボールトが読み取り、そこで承認すると、署名が別の QR コードになって返ります。

Osmosis や Injective で使えますか？

使えます。拡張機能は Cosmos のアプリがすでに使っている API をそのまま名乗るので、提供するウォレットの一覧に載ります。署名だけが、ブラウザのポップアップではなくオフライン端末を通ります。

ステーキングや委任はできますか？

ウォレットはアプリから届いたものに署名し、ボールトがそれを読み直します。ステーキングの画面は拡張機能そのものには入っていません。いつも使っているアプリで操作し、取引をオフライン端末で承認してください。
