来年インストールする価値のあるブラウザウォレットを、資金が自分のものであり続けるかを決める点で比べました。秘密鍵の置き場所、使えるチェーンと dApp、Ledger 対応、そして手数料です。

このリストを書いたのは誰か

Locker Protocol Wallet は私たちの製品で、ここでは1位に置いています。理由はひとつだけ、はっきり書きます。オプションとしてではなく設計として、秘密鍵をパソコンに一切保存しない拡張機能は、このリストでこれだけだからです。ほかの9本も同じ基準で比較し、それぞれについて私たちより優れている点を記しました。事実関係は2026年9月に、各ウォレットの公式サイト、ドキュメント、ストアの掲載内容で確認しています。

リストの作り方

秘密鍵の置き場所

暗号化されていても、ブラウザにある鍵は、悪意ある拡張機能ひとつ、感染したマシン一台で抜かれてしまいます。切り離されたオフライン端末にあれば、パソコンから盗めるものは何もありません。

チェーンと dApp

その拡張機能がどのブロックチェーンを扱えるか、そして普段使っているアプリが接続ボタンを押したときに見つけてくれるか。

ハードウェアとオフライン署名

鍵をパソコンの外に置けるかどうか。Ledger などのハードウェアウォレット、あるいは QR コードで署名するエアギャップ端末です。

手数料

ウォレットのインストールは無料です。内蔵のスワップとブリッジはたいていそうではないので、ウォレット自身が公開している上乗せ分を記載しました。

透明性と実績

コードが公開されているか、そしてその拡張機能がどう歩んできたか。インシデントはウォレットの歴史の一部であり、それをどう処理したかもまた同じです。

日々の使い勝手

送金、スワップ、署名にどれだけ手間がかかるか、そしてどのブラウザに公式ストアからインストールできるか。

Locker Protocol Wallet 自社製品

鍵をパソコンから完全に切り離したい人に

いま使っている dApp とそのまま動くブラウザ拡張機能で、秘密鍵は無料の Locker Vault アプリを入れた別のオフライン携帯電話に置いたままです。取引はそのつど QR コードで表示され、携帯電話の画面で確認してそこで承認すると、署名が別の QR コードになって返ってきます。9つのチェーンファミリーがひとつのリカバリーフレーズから生まれ、MetaMask、Keplr、TronLink、Freighter 向けに作られた接続ボタンが自分で見つけてくれます。

強み

  • ブラウザに秘密鍵がないため、パソコンのマルウェアや悪意ある拡張機能に盗むものがありません。
  • EVM チェーン、Solana、Bitcoin、Cosmos、Tron、Sui、Aptos、Stellar、XRP Ledger をひとつの拡張機能で扱え、スワップ、ブリッジ、Hyperliquid の無期限先物も内蔵しています。

弱み

  • 署名のたびに2台目の端末でスキャンが必要でワンクリックより遅く、ウォレットのソースコードは公開されていません。

MetaMask

対応 dApp の広さで選ぶなら

Consensys が提供する、ほとんどの dApp が前提にしている拡張機能です。あらゆる EVM ネットワークに加えて2025年5月から Solana、2025年12月から Bitcoin をネイティブに扱い、Ledger や Trezor から Keystone、GridPlus まで、ここに挙げたどの拡張機能より多くのハードウェアウォレットで署名できます。

強み

  • EVM の dApp はまずこれに対応し、Solana と Bitcoin のアカウントも同じ拡張機能の中にあります。
  • ハードウェア対応が最も広い。Ledger、Trezor、GridPlus Lattice、Keystone ほかの QR ウォレット。

弱み

  • ハードウェアウォレットをつながない限り鍵はブラウザにあり、内蔵スワップには 0.875% の MetaMask 手数料がかかります。

Phantom

Solana を使うなら

Solana エコシステムの定番ウォレットで、スワップ、トークン、NFT が磨き込まれたひとつの拡張機能にまとまっています。Ethereum、Base、Polygon、HyperEVM、Bitcoin も扱え、ケーブルでつないだ Ledger で署名できます。Sui への対応は2026年9月24日に終了しました。

強み

  • Solana の使い心地が最もなめらかで、Solana の dApp が最初に挙げるウォレットです。
  • 拡張機能から Ledger で署名でき、Nano S Plus、Stax、Flex に対応します。

弱み

  • Trezor に非対応、Firefox 版の更新は終了、Arbitrum、Optimism、BNB Chain もありません。多くのスワップに 0.85% の手数料がかかります。

Rabby Wallet

EVM ネットワークで安全に署名するなら

DeBank が Ethereum と EVM ネットワーク向けに作ったウォレットです。署名する前に、その取引で残高がどう変わるかを見せ、危険な承認に警告を出します。コードは MIT ライセンスで公開されています。

強み

  • 署名のたびに、残高の変化とリスク警告が先に表示されます。
  • MIT のオープンソースで、Ledger や Trezor などのハードウェアウォレットに対応します。

弱み

  • Ethereum と EVM ネットワークに絞られており、内蔵スワップには 0.25% の手数料がかかります。

よくある質問

いちばん安全な仮想通貨ウォレットの拡張機能は？

秘密鍵をパソコンの外に置くものです。暗号化されていても鍵を保存するブラウザ拡張機能は、マルウェア、悪意ある拡張機能、フィッシング署名によって空にされることがあります。拡張機能をハードウェアウォレットと組み合わせるか、鍵がエアギャップ端末にあるものを使えば、そのリスクはなくなります。パソコンが目にするのは、公開アドレスと署名済みの取引だけです。

2027年も MetaMask が最良のウォレット拡張機能ですか？

EVM の dApp がいちばん多く前提にしている拡張機能であることは変わらず、ほかの多くのウォレットも同じインターフェースに応えます。最良かどうかは、何を持っているかによります。MetaMask はハードウェアウォレットをつながない限り鍵をブラウザに置きますし、対応チェーン、手数料、セキュリティ設計で MetaMask にないものを備えた拡張機能もあります。

Ledger と一緒に使えるウォレット拡張機能は？

表のとおり、このリストのほとんどの拡張機能は Ledger 端末で署名できます。Ledger は、差し込んで使う USB または Bluetooth の端末に鍵を置きます。エアギャップのウォレットはさらに一歩進み、署名する端末をパソコンにいっさい接続せず、QR コードだけでデータをやり取りします。

エアギャップウォレットとは何ですか？

秘密鍵を、どのネットワークにもつながらない端末に置くウォレットのことです。Wi-Fi も USB も Bluetooth もありません。取引は QR コードで行き来するので、インターネットの側から鍵に届く経路がありません。Locker Vault は、使っていない携帯電話を無料でその端末に変えます。

ひとつの拡張機能で MetaMask、Phantom、Keplr を置き換えられますか？

できる場面が増えています。マルチチェーンの拡張機能は、ひとつのリカバリーフレーズで EVM チェーン、Solana、Cosmos をカバーするようになりました。問題は、お使いの dApp が検出してくれるかどうかです。Locker Protocol Wallet は MetaMask、Keplr、TronLink、Freighter 向けに作られた接続フローに応え、Solana、Sui、Aptos では Wallet Standard の一覧に表示されます。

仮想通貨ウォレットの拡張機能は無料ですか？

ここに挙げたウォレットは、インストールも保有も無料です。内蔵のスワップとブリッジには、ネットワーク費用とは別にウォレットが上乗せする手数料がかかるのが普通で、その額はウォレットごとに違います。Locker Protocol Wallet が上乗せするのは、スワップとブリッジで最大 0.25%、Hyperliquid の注文で 0.05% で、署名の前に表示されます。

鍵を預からない拡張機能を試す

Chrome か Brave に Locker Protocol Wallet を入れ、使っていない携帯電話に無料の Locker Vault を用意して、いつもの dApp をそのまま使ってください。
