Frequently Asked Questions

How do I connect to the Robinhood Chain on Locker Protocol?
Simply click the network selector modal in the upper right corner of the Locker Protocol application and select 'Robinhood Chain'. If the network is not configured in your MetaMask or other EVM wallet, the application will prompt you to automatically add and configure the chain ID 4663 network configuration.
Can I lock Robinhood Stock Tokens (AAPL, NVDA, TSLA, etc.)?
Yes. The official Robinhood Stock Tokens are standard ERC-20 contracts on the Robinhood Chain. Locker Protocol recognizes their canonical contract addresses, displays verified status badges, and supports creation of secure temporal and price-conditioned locks for these assets.
How are prices calculated for LP pairs and price-conditioned locks?
Locker Protocol utilizes a dynamic on-chain PriceCalculator contract that interacts directly with Uniswap V2 and Uniswap V3 pricing pools. The interface integrates the DexScreener API and on-chain factory registry checks to resolve pricing structures cleanly.
