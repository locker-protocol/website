How to connect Sanctum

1

Install the extension and the Vault

Add Locker Protocol Wallet to Chrome or Brave, and set up the free Locker Vault on a spare phone that stays offline.

2

Choose "Locker Protocol Wallet"

Open Sanctum, press its connect button and pick "Locker Protocol Wallet" in the list, then approve the connection in the extension.

3

Sign on the offline device

When Sanctum asks for a signature, the extension shows a QR code. Scan it with the Vault, read the transaction there, approve it, and scan the answer back.

On Solana, each transaction is simulated before you sign it, and the programs it calls are named on the review screen.

Sanctum and Locker: questions people ask

Is it safe to use Sanctum with Locker Protocol Wallet?

The wallet cannot make any site safe, but it changes what an attacker can do: the key never touches the computer, every transaction is shown on the offline device before you approve it, and risky approvals and known phishing sites are flagged first.

Which button do I pick on Sanctum?

"Locker Protocol Wallet". That is the entry Sanctum showed for the wallet when we checked it on 2026-09-17. Sites change their menus, so if it has moved, look for Locker Protocol Wallet or the generic browser wallet entry.

Do I need a hardware wallet to use Sanctum this way?

No. The key lives on the Locker Vault, a free app you install on a spare phone and keep offline. Transactions travel to it and back as QR codes, with no cable and no Bluetooth.

Does Locker Protocol Wallet add a fee on Sanctum?

No. Using Sanctum through the wallet costs only what Sanctum and the network charge. The wallet's own fee applies to swaps and bridges made from the extension itself (at most 0.25%), shown before you sign.
